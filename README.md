#  CLI To-Do List App (Python + SQLite)

Welcome! This is a simple, command-line-based task manager built with Python. It combines **Object-Oriented Programming (OOP)** principles with an **SQLite** database to keep your daily tasks organized and saved securely on your computer.

Instead of losing your tasks every time you close the terminal, this app writes everything to a local database file, meaning your data stays right where you left it.

##  Key Features
* **Built to Last**: Uses SQLite to save your tasks locally (`tasks.db`), keeping your data intact between sessions.
* **Smart Structure**: Built around a dedicated `Task` class, keeping the code clean, modular, and easy to expand.
* **Readable Tables**: No messy text walls here! Your tasks are neatly formatted into a readable table.
* **No Extra Setup**: Built entirely using Python's standard library, so you don't have to install any external dependencies.

##  What You Can Do
* **Add Tasks**: Quickly save new items with a title, a brief description, and a due date.
* **Track Progress**: View your active list and check off completed tasks.
* **Clean Up**: Easily remove outdated or accidental entries.



##  Getting Started

### Prerequisites
All you need is **Python 3.x** installed on your system. Python's built-in `sqlite3` tool handles the rest automatically.

### Running the App
1. Open your terminal or command prompt.
2. Navigate to the project folder.
3. Launch the app by running:
   ```bash
   week4_assignment.py```
